📝 Quiz Application

A simple Python-based Quiz Application that allows users to answer multiple-choice questions and keeps track of their score.

✨ Features

- Multiple-choice questions
- Interactive quiz interface
- Automatic answer checking
- Score tracking
- Final score display
- Simple and easy-to-use interface

🛠️ Technologies Used

- Python

📌 Project Purpose

This project was created to practice Python concepts such as conditional statements, loops, functions, user input, lists, and score calculation.
